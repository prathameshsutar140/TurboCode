**TurboCode IDE** is a professional C/C++ development environment combining the legendary **Borland Turbo C++ 3.0** aesthetic with modern IDE architecture, Monaco Editor, real compiler execution, and student-focused sandboxing.

#### 🌟 Key Engineering Highlights:
- **Dual Visual Experience**: Seamlessly toggle between authentic DOS Classic Turbo Blue (`#0000a8`) and sleek Modern Dark/Light themes.
- **Real Compilers (No Fakes)**: Direct invocation of native `gcc` and `g++` supporting C90–C17 and C++11–C++20 standards.
- **Diagnostic Jump Navigation**: Real-time parser for GCC error output; clicking an error in the Problems dock jumps Monaco Editor to the exact line and column.
- **Sandboxed Execution**: Win32 Job Objects RAM limiting (128 MB) and monotonic timeout protection (`SIGKILL` tree termination).
- **Integrated Debugger**: Live x86_64 disassembly and symbol table inspection powered by GNU GDB.
- **Built-in Practical Library**: 22+ educational programs covering pointers, memory allocation, OOP, and STL containers.

🛠 **Tech Stack**: Electron • Node.js • TypeScript • React • Monaco Editor • GCC/G++ • GNU GDB • Tailwind CSS • Win32 Job Objects
